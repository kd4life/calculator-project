# Python Calculator

A command-line calculator built in Python while I was learning functions, loops, input validation, and number conversion.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Reuse the same numbers
- Enter new numbers
- Exit the program
- Basic support for written numbers from zero through ten

## What I Learned

This project helped me practice:

- Writing and calling functions
- Using `if`, `elif`, and `else`
- Building loops
- Validating user input
- Converting strings into numbers
- Handling division by zero
- Debugging and improving a program step by step

## Current Status

The calculator is still being improved. I am currently refining how it converts written and decimal inputs.
